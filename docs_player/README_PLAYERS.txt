REALMQUEST - Beyond the Veil
============================

Start the game: double-click RealmQuest.exe (keep it inside this folder: it needs the
assets, audio and config folders next to it).

CONTROLS
  WASD / arrows   move                Space / J / left click   attack
  K  U  F         skills              Shift                    dash
  E               talk / use          H                        potion
  I               gear                Tab                      journal
  M               map                 Esc                      pause / settings

WHERE THINGS ARE
  Your save:     %APPDATA%\RealmQuest\savegame.json   (paste %APPDATA%\RealmQuest into Explorer)
  Settings:      %USERPROFILE%\.realmquest_settings.json
  If the game ever crashes, it writes %APPDATA%\RealmQuest\crash.log - please send that file.

TUNING
  The numbers of every monster, boss and hero class are in the config folder (one .toml file
  each). Open one in Notepad, change a number, save - the running game picks it up within a
  second. Delete a line to get the built-in value back.

LEVELS
  Goblin Dungeon  Lv 5-10      Berserker Dungeon  Lv 15-20      Lich King  Lv 20-30
  The mini dungeons and the monsters out in the vale help you get there.
