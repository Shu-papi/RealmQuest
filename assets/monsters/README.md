# Monster art

One folder per monster: `assets/monsters/<monster_name>/` with `frames.png` + `sprite.json`
(format explained in `src/monsters/HOW_TO_ADD_A_MONSTER.md`).

* `preview_all_variants.png`: the skeleton family in all five variants (bone, cursed, frost, ember, plague).
* `preview_animations.png`: every animation frame of every skeleton (idle, walk, windup, strike, recover, hurt).

The skeleton family's PNGs are generated by `src/monsters/dev/make_sprites.py` from a small bone rig (run it to
rebuild them), but you can also paint over them by hand in any pixel editor.

If a monster's art is missing or broken the game does not crash: it draws a plain placeholder and prints a warning.
