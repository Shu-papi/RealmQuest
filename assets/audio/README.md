# Audio files

`sfx/`   short sounds. `name.wav`, or `name__v1.wav`, `name__v2.wav` ... (a random variant is played).
`music/` looping tracks (`lich_p1/p2/p3.wav`).

Format: WAV, mono, 16-bit, 22050 Hz. Replace any file with your own recording of the same name.
Loudness and behaviour of each sound: `src/audio/sounds.py`. Full guide: `src/audio/README.md`.
