# Audio credits

Every sound and music file in `sfx/` and `music/` is generated by code (`src/audio/dev/`). No third-party audio is included.

`src/audio/dev/import_pack.py` can optionally swap in sounds from "Classic Monster Sounds" by Coucassi
(https://coucassi.itch.io/free-monster-sounds) on a local machine. Its terms: credit Coucassi, and do NOT post the
sounds anywhere (including a public GitHub repo) without the author's permission, so never commit those files.
